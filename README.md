# Attensi: Technical Case - Frontend Developer

Willy Wonka’s Chocolate Factory wants its trainers to build training scenarios themselves instead of relying on someone else to create them. Your task is to build the first piece of that tool: an ordered list of training steps. The trainers know chocolate, not code, so the interface should be easy to use and forgiving of mistakes. This is a frontend task, with a free choice of stack and TypeScript preferred, scoped to a maximum of 90 minutes.

## Requirements

### Step List

- Display a scenario as an ordered sequence of steps.
- Each step has a title and a body of text.

### Step Management

- Add a step.
- Edit a step’s title and text.
- Reorder steps.
- Delete a step.

### Scope

- No preview, branching, or backend is needed. Keeping everything in memory is fine.
- One file or a full project is acceptable.
- Stop after 90 minutes, even if unfinished. A finished product and visual polish are not expected; the focus is on state modelling, usability, and what was left out.

## Running the project

Install dependencies and start the development server:

```sh
npm install
npm run dev
```
